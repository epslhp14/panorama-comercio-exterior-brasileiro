# Vídeo demonstrativo

Demonstração do projeto Panorama do Comércio Exterior Brasileiro (2020–2025).

O vídeo apresenta:
- Banco de dados SQLite e execução de consultas SQL no Letos.
- Modelagem de dados e relacionamentos no Power BI.
- Navegação pelas três páginas do dashboard.
- Análise de indicadores, mercados internacionais e produtos exportados.
