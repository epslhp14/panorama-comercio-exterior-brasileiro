# Consultas SQL

Consultas desenvolvidas para análise das exportações brasileiras entre 2020 e 2025.

## Conteúdo

- Evolução anual e análise semestral das exportações
- Rankings de países e produtos
- Consultas com JOIN
- Comparações de crescimento
- Análises de concentração
- Verificação de consistência e qualidade dos dados

**Banco de dados:** SQLite 3  
**Ferramenta:** Letos 4.0.4
